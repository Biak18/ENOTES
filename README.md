# ENOTES ERP System

ENOTES is a desktop ERP system built with .NET WinForms.  
It uses **MDI (Multiple Document Interface)**, allowing you to manage multiple projects within a single application.


## Tech Stack
- .NET 8 (WinForms)
- SQL Server
- DevExpress UI

## Features
- User authentication
- Role-based access control
- Notes management
- Clean ERP-style UI

## Setup
1. Clone the repo
2. Run the ENOTES.exe from the Dev_Deploy
3. Login with SYSTEM\SYSTEM\1 for the first time
4. Add some menu in Master Menu/Company registration for your company
